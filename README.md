# CVD-with-Diabetes-

# Cardiovascular Disease Prediction System
A web-based machine learning project to predict the likelihood of cardiovascular disease in individuals with diabetes. This system uses CatBoost and XGBoost algorithms to analyze health-related input data and provide risk predictions. The frontend is built using HTML, CSS, and JavaScript, while the backend is powered by Python.

# Project Overview
This project aims to support early detection of cardiovascular disease among diabetic patients by leveraging machine learning models trained on clinical datasets. The system is capable of taking relevant health metrics as input and classifying the risk level of heart-related conditions.

 # Features
- Input form for relevant health data (e.g., age, BMI, glucose level, blood pressure)

- Real-time prediction using trained ML models

- Interactive and responsive web interface

- Model performance evaluation (accuracy, precision, recall, F1-score)

- Comparison between CatBoost and XGBoost predictions

# Machine Learning
Algorithms Used:
- CatBoost – Gradient boosting on decision trees with categorical features support.

- XGBoost – High-performance gradient boosting algorithm.

Dataset:
- Diabetes-related dataset containing clinical data used to train and test the model.

- Features include age, gender, glucose, BMI, smoking status, etc.

# Model Workflow:
